# Cabaña en el bosque · 4K

Un minuto en una cabaña de madera, de noche, con nieve en el bosque y la chimenea encendida. Cuatro planos quietos, sin gente, sin música.

1. La cabaña entre los pinos, humo en la chimenea, nieve cayendo.
2. La sala: piedra, sillón, manta y fuego.
3. El fuego de cerca, leña y brasas.
4. La ventana con escarcha, la luna y una taza.

El archivo de un minuto se publica en el release cuando termina el máster 4K. El loop de doce horas se hará después, cuando este corte esté bien.
